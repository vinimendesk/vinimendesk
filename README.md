### 🤖 Retail Demand Intelligence

Machine Learning project developed with **Databricks**, focused on forecasting daily sales by store.

The project implements an end-to-end Machine Learning pipeline covering data ingestion, data quality validation, temporal feature engineering, data leakage prevention, temporal train/validation/test splitting, model training, evaluation, experiment tracking with MLflow, Model Signature, and model registration in Unity Catalog.

**Final Model:** Random Forest Regressor
**RMSE:** 1043.12
**MAE:** 659.35
**R²:** 0.9247

*Stack: Databricks, Apache Spark, Spark ML, MLflow, Python, SQL*
